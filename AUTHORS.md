## Créditos

MdMax foi desenvolvido com ❤️ para economizar tokens do Claude e reduzir custos de API.

### Bibliotecas e Dependências

- **Python 3.8+** - Linguagem base
- **Tesseract OCR** - Extração de texto em imagens
- **ebooklib** - Processamento de EPUB
- **Pillow** - Manipulação de imagens
- **python-docx** - Processamento de DOCX
- **python-pptx** - Processamento de PPTX
- **openpyxl** - Processamento de XLSX

## Contribuições

Estamos abertos a contribuições! Se você quer ajudar:

1. Abra uma **Issue** descrevendo sua ideia
2. Faça um **Fork** do projeto
3. Crie uma **Branch** com seu nome: `git checkout -b feature/sua-feature`
4. Commit suas mudanças: `git commit -m "Add nova feature"`
5. Push para a branch: `git push origin feature/sua-feature`
6. Abra um **Pull Request**
