TROUBLESHOOTING QUICK FIXES
─────────────────────────────────────────────────────────────────────────────

Problem: "command not found: mdmax"
Solution: pip install --upgrade pip && pip install mdmax

Problem: "Hook not triggering"
Solution: mdmax --setup-hook

Problem: "OCR not working"
Solution: Install Tesseract separately (see Optional Dependencies)

Problem: "Need to reset everything"
Solution: mdmax --clear-cache && mdmax init
