## 🔧 Configuração (config.json)

```json
{
  "default_mode": "ultra",              // Padrão: ultra (70% economia)
  "cache_cleanup_days": 7,              // Limpar cache > 7 dias
  "enable_logging": true,               // Logs detalhados
  "parallelization": {
    "enabled": true,
    "workers": 3                        // 3 arquivos em paralelo
  },
  "optimize_tokens": {
    "aggressive": true,                 // Otimização agressiva
    "remove_metadata": true,
    "compress_tables": true
  }
}
```
